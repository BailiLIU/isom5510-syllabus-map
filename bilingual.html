Topic 0 · What Do the Data Tell Us? / 数据告诉我们什么？

Syllabus：Describing data & probability / 描述数据与概率；总结 messy data、识别 pattern、描述 randomness。

0.1 描述数据 / Describing Data
Data types 数据类型Center 中心Spread 离散程度Distribution 分布Visualization 可视化
数据结构 / Data structure

中文：先识别变量是什么、变量类型、单位与类别，建立对数据集的基本结构认识。
EN: Identify variables, their scales, units, and categories before analyzing them.

集中趋势 / Central tendency

中文：mean、median 等回答“典型值在哪里”。
EN: Mean and median summarize where observations are centered.

变异 / Variation

中文：range、variance、standard deviation 等回答“数据有多分散”。
EN: Range, variance, and standard deviation summarize dispersion.

形状与模式 / Shape & pattern

中文：偏态、聚类、异常值、多峰等决定数据的实际结构。
EN: Skewness, clusters, outliers, and multimodality reveal structure beyond averages.

0.2 概率与随机性 / Probability & Randomness
随机变量 / Random variable

中文：把不确定结果映射成数值。
EN: A numerical representation of an uncertain outcome.

概率分布 / Distribution

中文：描述可能结果及其概率。
EN: Describes possible outcomes and how probability is assigned.

期望与方差 / Expectation & variance

中文：期望表示长期中心，方差表示围绕中心的波动。

概率是后面 sampling distribution、confidence interval、hypothesis testing 的数学语言。 / Probability is the language used later for sampling distributions, confidence intervals, and tests.

Topic 1 · Can We Learn About Many from a Few? / 能否从少量样本了解总体？

Syllabus：Sampling & estimation / 抽样与估计；重点回答“如何选好样本”“如何估计无法完全观察的总体”“为什么不同样本得到不同答案”。

1.1 总体、样本、参数、统计量 / Population, Sample, Parameter, Statistic
概念 / Concept中文English
Population真正关心的完整总体。The full group of interest.
Sample实际被观察到的总体子集。The observed subset.
Parameter总体的真实数值特征，通常未知。A numerical property of the population, usually unknown.
Statistic由样本计算得到，用于估计 parameter。A sample-based numerical summary used to estimate a parameter.
1.2 抽样设计与代表性 / Sampling Design & Representativeness

中文：核心不是只问“样本够不够大”，而是“这个样本是怎么来的”。大样本如果存在系统性选择偏差，结论仍然可能错。

EN: The central issue is not only sample size, but how the sample was selected. A large sample can still be misleading if selection is systematically biased.

  • Simple random sampling：每一个固定大小的样本组合等概率。
  • Systematic sampling：从一个起点开始，以固定间隔抽样。
  • Selection bias / nonresponse：进入样本的人与没进入样本的人可能系统性不同。
  • Reproducibility：软件随机抽样时记录 seed，有助于复现。
1.3 点估计 / Point Estimation
均值 / Mean

样本均值估计总体均值。 / Sample mean estimates population mean.

比例 / Proportion

样本比例估计总体比例。 / Sample proportion estimates population proportion.

方差 / Variance

样本方差估计总体变异。 / Sample variance estimates population variability.

1.4 最大似然估计 / Maximum Likelihood Estimation (MLE)

中文：在假设的统计模型下，选择一个参数值，使“我们已经观察到的数据”出现的可能性最大。

EN: MLE chooses the parameter value that makes the observed data most plausible under the assumed model.

  • 确定模型 / Specify a model.
  • 写出 likelihood / Write the likelihood.
  • 对未知参数最大化 / Maximize over the unknown parameter.
  • 得到 point estimate / Use the maximizer as a point estimate.
1.5 抽样波动、LLN、CLT / Sampling Variability, LLN, CLT
Sampling variability

中文：不同随机样本会产生不同估计值。
EN: Different random samples yield different estimates.

LLN · 大数定律

中文：样本量增加时，平均值在合适条件下趋于稳定到总体均值。
EN: Averages stabilize around the population mean as n grows.

CLT · 中心极限定理

中文：在合适条件下，样本均值的抽样分布随着样本增大趋近正态，因此可以量化不确定性。
EN: The sampling distribution of averages becomes approximately normal under suitable conditions.

关键区别 / Key distinction
更多数据减少随机抽样波动，但不能自动修复 selection bias。 / More data reduces random sampling variability; it does not automatically fix bias.

Topic 2 · How Uncertain Is Our Answer? / 我们的答案有多不确定？

Syllabus：Confidence intervals & bootstrap / 置信区间与 bootstrap；重点是估计有多精确、一个数据集产生的数字到底该信多少。

2.1 标准误与精度 / Standard Error & Precision

中文：point estimate 只给一个数；standard error 描述如果重复抽样，这个 estimator 会波动多大。

EN: A point estimate is one number; standard error measures how much the estimator would vary across repeated samples.

  • SE 越小，估计越精确。 / Smaller SE means higher precision.
  • 通常 n 越大，SE 越小。 / Larger n usually reduces SE.
  • 精确不等于无偏。 / Precision is not the same as absence of bias.
2.2 置信区间 / Confidence Intervals

中文：用 point estimate 加上反映 sampling uncertainty 的误差范围，得到一个对 population parameter 的区间估计。

EN: A confidence interval combines a point estimate with a margin reflecting sampling uncertainty to produce a range of plausible parameter values under the method's assumptions.

2.3 Bootstrap

中文：从已观察样本中反复“有放回重抽样”，每次重新计算 statistic，用这些重复结果近似 estimator 的 sampling distribution。

EN: Bootstrap repeatedly resamples from the observed data and recomputes the statistic to approximate the estimator's sampling distribution.

Topic 3 · Is the Pattern Real, or Could It Be Chance? / 模式是真的，还是随机造成的？

Syllabus：Hypothesis testing / 假设检验；判断新策略是否真的更好、观察到的差异是否足够大到具有统计意义。

3.1 原假设与备择假设 / Null & Alternative Hypotheses
H₀ · Null hypothesis

中文：基准状态，例如“没有提升”“没有差异”。
EN: A benchmark such as “no improvement” or “no difference.”

H₁ · Alternative hypothesis

中文：希望由数据提供证据支持的竞争性结论。
EN: The competing claim supported if evidence against H₀ is strong enough.

3.2 检验统计量与 p-value / Test Statistic & p-value

中文：test statistic 衡量数据偏离 H₀ 的程度；p-value 表示在 H₀ 为真时，出现当前这么极端或更极端结果的“惊讶程度”。

EN: The test statistic measures departure from H₀; the p-value summarizes how surprising an equally or more extreme result would be if H₀ were true.

3.3 统计显著 vs 实际重要 / Statistical vs Practical Significance

中文：统计上可检测的差异，不代表商业上一定重要；effect size、成本、收益和决策后果仍需要单独判断。

EN: Statistical detectability does not automatically imply practical or business importance.

Topic 4 · How Are Variables Related—and What Can We Predict? / 变量如何关联，以及能预测什么？

Syllabus：Regression / 回归；分析哪些因素与 outcome 相关、如何预测，以及遗漏重要变量时会发生什么。

4.1 关系建模 / Relationship Modeling

中文：回归把 outcome 与一个或多个 explanatory variables 联系起来，关注关系方向、大小、不确定性以及拟合程度。

EN: Regression links an outcome to one or more explanatory variables and studies direction, magnitude, uncertainty, and fit.

4.2 预测 / Prediction

中文：建立关系模型后，可对新样本进行预测；预测是否可靠取决于模型设定和新数据是否与训练条件相近。

EN: Regression can predict new cases, but reliability depends on model specification and whether new cases resemble the estimation setting.

4.3 遗漏变量 / Omitted Variables

中文：如果遗漏了同时与 outcome 和某些 predictors 相关的重要变量，估计关系可能被扭曲。因此“相关”不能自动解释为“因果”。

EN: Omitting an important variable related to included predictors can distort estimated relationships, so association should not automatically be interpreted as causation.
